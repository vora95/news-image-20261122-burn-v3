# SUNDAY IN FULL

A one-page wire-service front page summing up the world news of Sunday
22 November 2026. A "THE DAY IN UTC" timeline strip runs the day hour by
hour — COP31 objections close at 03:00, Verstappen wins Las Vegas at
05:30, the Bayelsa toll rises to 24 at 07:34 — above one dominant COP31
lead (final text names no fossil fuels; plenary slips to 11:00 Antalya),
two half leads (Iran's strikes on US bases in Bahrain, the Sparta II still
burning off Finland), eight medium stories each carrying an epistemic chip
(CONFIRMED / CLAIMED / REPORTED with its outlet), a dotted world map with
numbered pins, 22 more stories, a separate SPORT strip, and a DATE CHECK
box that lists what was left out on purpose. 37 stories in all, every one
dated Sunday 22 November 2026, every one naming its outlet.

## Run

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`. Run it twice and both runs write the same
bytes:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
